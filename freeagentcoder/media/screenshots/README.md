# Screenshots

Drop the PNGs here using **exactly these filenames**. They are referenced from the
extension README (and the website) by raw GitHub URL, so they appear on the
Marketplace listing page without shipping inside the `.vsix`.

| Filename | What to capture |
| --- | --- |
| `chat.png` | A task mid-run: the plan checklist, a diff card, and the model chip visible |
| `keys.png` | Settings → API Keys, with the "stays on your device" note and one active key |
| `overview.png` | Settings → Overview: prompts left today, project status, feature switches |
| `correction.png` | A reply with the Correction chip, after pointing out a fix with a screenshot |
| `demo.gif` | *Optional.* 15–20s: type a request → plan appears → file edited → tests pass |

## How to capture

1. Use a real project, dark theme, and a chat panel about 500px wide.
2. `Win` + `Shift` + `S` → drag over **just the FreeAgentCoder panel**, not the whole window.
3. In the Snipping Tool notification that appears, click it, then **Save As** into this folder.
4. Keep each file under ~1 MB. PNG only (SVG is rejected by the Marketplace).

For `demo.gif`, [ScreenToGif](https://www.screentogif.com/) is free on Windows: record the
panel, trim, export as GIF, keep it under 10 MB.

Once the files are here, the README image block and the website gallery get wired up.
