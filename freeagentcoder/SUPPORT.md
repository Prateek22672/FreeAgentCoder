# Support

## Report a bug or ask for a feature

Open an issue: https://github.com/Prateek22672/FreeAgentCoder/issues

Include your VS Code version, OS, and (from **Settings → Logs → Copy diagnostics**) a diagnostics report — it never contains API keys.

## Ask a question

Use the **Q&A** tab on the [Marketplace page](https://marketplace.visualstudio.com/items?itemName=PrateekKoratala.freeagentcoder), or open a GitHub issue. Questions are answered, not left open.

## Response time

Issues and questions are typically answered within 24–48 hours.
